Finish setting up the admin

The admin needs two things in your Vercel project before anyone can sign in:

  1. A database for the league. In Vercel, open the gum-guildwars project, go to Storage, choose Create Database → Upstash for Redis, and connect it to this project.
  2. A setup key. In Settings → Environment Variables, add ADMIN_PASSWORD with a long password only you know.

Then redeploy the site and reload this page.
